# Agent Instructions

## Agent Skills

When creating, updating, or reviewing an agent skill, always consult and check
compliance with Anthropic's agent-skill best practices:

https://platform.claude.com/docs/en/agents-and-tools/agent-skills/best-practices

Use the current guide as the source of truth. At minimum, verify skill
frontmatter and discoverability, concise scope, appropriate degrees of
freedom, progressive disclosure, clear workflows, validation or feedback loops,
and consistent terminology. Apply only the guidance relevant to the skill being
changed and validate the result after editing.
